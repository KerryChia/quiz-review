# 出题与解析规范

目标不是「像教辅书」，是「像一个刚考完这门课的助教，把踩过的坑告诉你」。

---

## 一、先做考点地图

动笔前先列一张表，自己看得懂就行：

| 板块 | 资料出处 | 核心考点 | 题数 | 题型 |
| --- | --- | --- | --- | --- |
| A 绪论 | 第 1 讲 | 复杂度、均摊 | 12 | 选择 6 / 判断 2 / 填空 2 / 简答 2 |

规则：

- 考点必须能在资料里找到出处。找不到的不要出。
- 一个板块内每个考点至少 2 题，重要考点 3–5 题。
- 老师重复讲、PPT 标红、往年真题出现过的，题量翻倍。

---

## 二、四类题怎么写

### 选择题

- 四个选项，**干扰项要像真的**：用学生真会犯的错，而不是明显胡话
- 错误选项最好是「算错一步」「混淆概念」「漏条件」的产物
- 不要出现「以上都对 / 以上都不对」
- 正确答案的位置要打散，别连着五个 B
- 题干只问一件事，别把三个知识点塞进一道题

反例：

> 下列关于算法的说法正确的是？
> A. 算法就是程序  B. 以上都对  C. 算法必须有限  D. 不知道

正例：

> 某算法在最好情况下比较 $n$ 次，最坏情况下比较 $n^2$ 次，则其时间复杂度记作：
> A. $O(n)$  B. $O(n^2)$  C. $O(n\log n)$  D. 无法确定
>
> 答案 B。大 O 看最坏情况的上界。

### 判断题

- 对错各占一半左右
- 错的题要错在**具体的一步或一个条件**上，不是整句胡说
- 避免出现「一定」「必然」「都」这类词导致的送分或送命
- 解析必须说清「错在哪」，不能只写「错误」

### 填空题

- 一题 1–4 空，答案短（一个词、一个式子、一个数）
- 答案不唯一时，把所有合理写法塞进 `alt`
- 数值答案标 `"kind": "num"`
- 不要让人填一整句话

正例：

```json
"fields": [
  { "label": "时间复杂度", "a": "O(n)" },
  { "label": "空间复杂度", "a": "O(1)", "alt": ["O（1）"] },
  { "label": "比较次数", "a": "n-1", "kind": "num" }
]
```

### 简答 / 计算

- 必须有明确的可判分步骤，答案是「过程」不是「一句话」
- `solution` 写成评分点清单，每条带分值，总和等于 `points`
- 3–5 条评分点最合适，多了学生没法自评，少了 AI 判不准
- 涉及计算要给出关键中间结果，学生能对照

```json
"solution": "**评分点（共 10 分）**\n\n- 正确写出递推式（3 分）\n- 展开或代入化简（3 分）\n- 得出闭式结果（2 分）\n- 说明边界条件（2 分）\n\n**易错**：忘记 $n=0$ 的初值。"
```

## 三、解析：三段式

每条解析都按这个骨架写，不要自由发挥：

```
**考点**：这道题在考什么（一句话）

- 步骤 1：用了哪条定义/公式，为什么
- 步骤 2：代入什么，得到什么
- 结论：答案

**易错**：学生最可能错在哪一步、为什么错
```

要求：

- 写「为什么」，不写「由题意得」
- 公式和数字要能对上，别跳步
- 选择题要逐个说 A/B/C/D 为什么对或错（至少说清正确答案和最强干扰项）
- 判断题说清错在哪个词
- 主观题在「易错」里点出扣分点

**禁止**：解析里写「略」「显然」「同理可得」而不展开。学生看解析就是因为不会。

## 四、难度分布

一套 150 题的题库，建议：

| 难度 | 占比 | 特征 |
| --- | --- | --- |
| 基础 | 50% | 定义、直接套公式、单步计算 |
| 中等 | 35% | 两步以上、需要选方法、常见变式 |
| 较难 | 15% | 综合、易混概念辨析、往年压轴 |

不要全是难题——刷不动会放弃；也不要全是送分题——没有提分效果。

板块内部也按「先基础后综合」排，别第一题就压轴。

---

## 五、模拟卷

有真题时单独建 `M` 板块（或 `M1`、`M2`），严格照抄真题的**结构**：

- 题型顺序：选择 → 填空 → 简答 → 计算
- 每题分值、总分
- 建议时长（写进 `subtitle`）

内容不要照抄原卷，改数字、换情境，保留考点和难度。题号用 `M1-1`、`M1-2` 这种。

## 六、公式写法的坑

| 想写 | 写法 | 注意 |
| --- | --- | --- |
| 分数 | `$\frac{a}{b}$` | 分子分母是整体时加花括号 |
| 根号 | `$\sqrt{x}$`、`$\sqrt[3]{x}$` | 目前只渲染平方根，三次根写成 $x^{1/3}$ |
| 求和 | `$\sum_{i=1}^{n} a_i$` | 上下标会自动缩小 |
| 积分 | `$\int_0^1 f(x)\,dx$` | 上下限写在 `_` `^` 后 |
| 分段 | `$$\begin{cases} x & x>0 \\ 0 & x\le 0\end{cases}$$` | `&` 对齐，`\\` 换行 |
| 组合数 | `$\binom{n}{k}$` | 也可写 `$C_n^k$` |
| 向量 | `$\vec{a}$` | **不支持** `\vec`，改用 `$\mathbf{a}$` 或 `$\bar{a}$` |
| 多字母下标 | `$x_{ij}$` | 花括号别省 |

常见错误：

- 只写一个 `$` → 整段变公式或直接坏掉
- 在 `\text{}` 里写中文公式 → 改成普通文字
- 用 `\[ ... \]` → 改成 `$$...$$`
- 用 `\\` 在普通文本里换行 → 普通文本直接换行即可

## 七、生成节奏

- 一次只写一个板块文件（10–30 题），写完立刻 `validate.py`
- 全部写完再跑一次总校验，重点看：题号重复、`$` 不成对、选择题答案不在选项里
- 题量大的时候，先把 `course.json` 和全部板块的 `id/name/notes` 写好，再逐个填题——结构稳了不容易返工

## 八、最后一遍自查

- [ ] 每个板块都有 `notes`，且能在 1 分钟内读完
- [ ] 每道题都有 `solution`，且解释了「为什么」
- [ ] 每道主观题都有评分点和分值
- [ ] 填空题的等价写法覆盖了学生的常见写法
- [ ] 没有两道题一模一样，没有题号重复
- [ ] 页面上的文字没有一句是废话

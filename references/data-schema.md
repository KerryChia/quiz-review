# 数据格式

两个东西：`data/course.json` 描述课程，`data/packs/*.json` 每个文件一个板块。

构建时按**文件名排序**拼接板块，所以用 `01-`、`02-` 前缀最稳。板块内部题目按数组顺序出，不按题号重排。

---

## course.json

```json
{
  "title": "数据结构与算法 · 期末复习",
  "mark": "D",
  "aiTutor": true,
  "storageKey": "demo-dsa"
}
```

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `title` | 是 | 页面标题、浏览器标签、顶栏课程名。带不带「复习」都行，别写口号 |
| `mark` | 否 | 左上角深色方块里的字符。中文取首字，英文取首字母 |
| `aiTutor` | 否 | 默认 `true`。`false` 时不注入 AI 助教，命令行 `--ai` / `--no-ai` 可覆盖 |
| `storageKey` | 否 | 进度存储键后缀。不填则用标题哈希。同一浏览器放多套题库时，**必须**各不相同 |

## 板块文件

```json
{
  "id": "A",
  "head": "A",
  "name": "绪论与复杂度",
  "subtitle": "大 O 记号、常见量级",
  "notes": "**大 O 只保留最高阶项。**\n\n- $O(1)<O(\\log n)<O(n)$",
  "questions": []
}
```

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `id` | 是 | 板块标识，同时是题号前缀。A、B、C 或 01、02 |
| `head` | 否 | Tab 上的前标，默认等于 `id` |
| `name` | 是 | 板块名，跟课件章节名一致 |
| `subtitle` | 否 | 侧栏标题下一行小字。一句话，或直接省略 |
| `notes` | 否 | 知识点梳理，强烈建议写。为空时页面隐藏折叠块 |
| `questions` | 是 | 题目数组，**不要为空** |

### notes 写法

- 200–500 字，3–6 个要点
- 用 `**粗体**` 标最容易忘的结论
- 公式用 `$...$`；独立成行用 `$$...$$`
- 行首 `- ` 出列表
- 空行分段

```json
"notes": "**顺序表与链表的取舍看访问模式。**\n\n- 顺序表：随机访问 $O(1)$，插入删除 $O(n)$\n- 链表：按下标访问 $O(n)$，已知前驱插入 $O(1)$\n\n易错：链表的 $O(1)$ 插入前提是**已经拿到前驱**。"
```

## 题目公共字段

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `id` | 是 | 全局唯一，如 `A1`、`A2`、`M1-3` |
| `type` | 是 | `choice` / `judge` / `fill` / `subjective` |
| `stem` | 是 | 题干 |
| `note` | 否 | 题干下方小字，用于补条件、单位、提示 |
| `points` | 否 | 分值，显示成标签；主观题建议必填 |
| `solution` | 是 | 解析，答错或点「查看参考答案」时展示 |

### choice 单项选择

```json
{
  "id": "A1",
  "type": "choice",
  "points": 5,
  "stem": "下列说法正确的是：",
  "options": [
    ["A", "$O(1)$ 表示执行时间为 0"],
    ["B", "$O(n)$ 与 $O(2n)$ 同阶"],
    ["C", "$O(n^2)$ 总比 $O(n\\log n)$ 快"],
    ["D", "空间复杂度与规模无关"]
  ],
  "answer": "B",
  "solution": "**考点**：大 O 忽略常数因子。\n\n- A 错：…\n- B 对：…"
}
```

- `options` 每项是 `["key", "文本"]`，一般 4 项
- `answer` 写 **key**（`"B"`），不要写选项文本

### judge 判断

```json
{
  "id": "A2",
  "type": "judge",
  "stem": "顺序表插入平均移动约 $n/2$ 个元素。",
  "answer": "对",
  "solution": "…"
}
```

`answer` 只能是 `"对"` 或 `"错"`。

### fill 填空

```json
{
  "id": "A3",
  "type": "fill",
  "points": 6,
  "stem": "邻接表存储 $n$ 个顶点、$e$ 条边的无向图，空间为 ____。",
  "fields": [
    {
      "label": "空间复杂度",
      "a": "O(n+e)",
      "alt": ["O(n + e)", "o(n+e)"],
      "kind": "text"
    }
  ],
  "solution": "…"
}
```

| 字段 | 说明 |
| --- | --- |
| `label` | 这一空的说明，显示在输入框上方 |
| `a` | 标准答案 |
| `alt` | 等价写法数组，可省略 |
| `kind` | `text`（默认）或 `num` |

判定规则：

- `text`：忽略大小写、全角半角、空格、首尾标点、上下标后比较，命中 `a` 或任一 `alt` 即对
- `num`：把答案和 `a`/`alt` 都解析成数字（支持 `2/3`、`1e-3`），误差小于 `1e-3` 即对

数值答案一定要标 `"kind": "num"`，否则 `0.5` 和 `1/2` 判不上。

### subjective 简答 / 计算

```json
{
  "id": "B3",
  "type": "subjective",
  "points": 10,
  "stem": "写出单链表就地逆置的核心步骤，并给出时空复杂度。",
  "solution": "**评分点（共 10 分）**\n\n- 断开原链，保存首结点（2 分）\n- 循环头插，先暂存后继（4 分）\n- 推进指针至空（2 分）\n- 时间 $O(n)$，空间 $O(1)$（2 分）\n\n**易错**：不暂存后继会断链。"
}
```

评分点写清楚，AI 判卷就是照这个给分的。没有评分点，AI 只能凭感觉打分。

## 文本语法

`stem`、`note`、`solution`、`notes`、`subtitle`、选项文本都支持：

| 写法 | 效果 |
| --- | --- |
| `**文字**` | 粗体 |
| `` `代码` `` | 行内代码 |
| `$x^2$` | 行内公式 |
| `$$...$$` | 独立居中的公式行 |
| 空行 | 分段 |
| 行首 `- ` | 列表项 |
| 单个换行 | 换行（`<br>`） |

不支持：`#` 标题、Markdown 表格、图片、链接、HTML 标签。

### 公式白名单

支持：`\frac \sqrt \sum \prod \int \lim \log \ln \exp \max \min \sin \cos \tan`、`^ _`、`\bar \hat \tilde \overline`、`\binom`、`\begin{cases}…\end{cases}`、`\left \right`、`\mathrm \text \mathbf`，以及常用希腊字母、关系与集合符号。

不支持：`align`、`matrix`、`array`、`\substack`、`\color`。

多行公式用多个 `$$...$$`，或 `\begin{cases}` 分情况。

## JSON 书写注意

1. 文件必须是 UTF-8，无 BOM
2. 不能有注释、不能有尾逗号
3. 反斜杠要双写：`"$\\frac{1}{2}$"` 表示 $\frac{1}{2}$
4. `</` 会被构建脚本转义，正常写即可
5. 一个板块一个文件，单文件建议不超过 1 MB

写完一个文件就跑一次：

```bash
python <repo>/scripts/validate.py --data data
```
